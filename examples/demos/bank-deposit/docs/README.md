# Bank deposit: learn S++ through financial agreements

A deposit is more than adding an amount to a balance. This example makes
eligibility, debt allocation, postings, accrual and reversal explicit.

## Reading path

1. [From one sentence to an S++ model](implementation-path.md): the five-step development method.
2. [Language tour](language-tour.md): roles, contracts, checks, calculations and quantum settlement.
3. [Domains and layers](domain-and-layers.md): entity ownership and SPP/APP/PHY boundaries.
4. [Business rules](business-rules.md): allocation, conservation and original-trade reversal.
5. [Validate the model](validation-guide.md): observable outcomes, boundaries and failures.
6. [Run the demo](running-demo.md): generation, tests and the workbench.

Read the [current source tree](../src/main/spp/cboddeposit/) alongside each guide.
This is a selected banking demonstration, not a complete core banking system or
a production certification. Business parameters in examples are not live bank policy.
